# Neutral Emotify — Legacy Player

The original music player interface built for the **Emotify** project — a React-based player that served emotion-matched music in real time.

> **⚠️ Archived**
> This player is no longer active. The backend server links that powered the emotion-detection pipeline have been shut down. This repository is preserved as the legacy frontend of the Emotify project.

## Overview

`neutralemotify` was the standalone React player UI component of Emotify — responsible for receiving emotion data from the detection server and playing back the corresponding music playlist in real time.

## Project Structure

```
neutralemotify/
├── src/          # React player components and logic
├── public/       # Static assets
├── package.json  # Dependencies
└── .gitignore
```

## Running Locally

```bash
npm install
npm start
```

> Note: The player UI will load, but music playback and emotion sync will not function as the backend server is no longer active.
